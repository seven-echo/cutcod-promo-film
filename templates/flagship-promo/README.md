# 网站镜头

这一页不另画界面。它挂上 `src/shots/sites.jsx` 里现成的两个镜头，走 `src/kit/siteShot.jsx` 同一套相机、光标、荧光笔和字幕：

1. `site`（影片 8–12 秒）：1440×900 的真实页面，放大 1.3334 铺满 1920×1080。光标依次点三个分类。
2. `code`（影片 12–24 秒）：同一台相机接下去。点「视频源代码」，黄笔扫过「节省95%token」，打开第一张卡（画面 246×246），点「复制」，黑提示「已复制」，再推近复制框。

`plan.json` 和 58 秒成片不读这个目录。预览：

```sh
node templates/flagship-promo/preview.mjs
```

卡片封面和片中画面不在仓库里。先 `npm run setup`，否则网格只有空框。
