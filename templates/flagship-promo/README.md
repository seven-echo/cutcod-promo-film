# 15 秒宣传模板

给 CutCod 用的可复用成片，不是 58 秒那条片子的一场。`plan.json` 和 `npm run film` 都不读这个目录。

镜头语法来自一条手写旗舰片：一个物体贯穿全片，每一镜换一种动作，相邻镜头重叠大约 0.4 秒。这里的贯穿物体是同一张「UI 形变 / 源代码」资源卡。配色用本仓库的奶白 `#f7f7f7`、墨色 `#171717`、荧光黄 `#f1f32d`。不用暗场、粒子、蓝紫发光、回弹和 3D 倾斜。

| 秒 | 镜头 | 主动作 |
|---|---|---|
| 0.00 | 开场 | 逐词上滑，卡片从右侧进入，荧光笔扫过 |
| 2.35 | 三种做法 | 色块从左侧擦开，三张卡错开滑入 |
| 4.55 | 复制 | 遮罩擦开，同一张卡上的按钮按下 |
| 6.55 | 甩词 | 黑带纵向展开，三个词横穿 |
| 8.15 | 结果 | 格子上移，步骤打勾，数字计数，盖章 |
| 10.85 | 口号 | 圆形擦开，荧光笔再扫一次 |
| 12.85 | 落版 | 品牌字逐字落下 |

预览需要已安装依赖（仓库里的 `gsap`）：

```sh
npm ci --ignore-scripts
node templates/flagship-promo/preview.mjs
```

浏览器控制台：`seek(8)`、`playFilm()`。加 `?render=1` 关掉底部拖条。画面 1920×1080，30 fps，片长 15 秒。
